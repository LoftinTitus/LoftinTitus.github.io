# Titus Loftin - Personal Portfolio Website

A modern, responsive portfolio website showcasing my skills, projects, and professional experience. Built with clean HTML, CSS, and JavaScript to demonstrate web development capabilities and provide an engaging user experience.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly across desktop, tablet, and mobile devices
- **Interactive Navigation**: Single-page application with smooth section transitions
- **Contact Integration**: 
  - Direct email functionality using EmailJS
  - Meeting scheduler with Google Calendar integration
- **Modern UI/UX**: 
  - Clean, professional design
  - Smooth animations and transitions
  - Mobile-first approach with collapsible sidebar
- **Skills Animation**: Continuous sliding animation for technical skills showcase

## Technologies Used

### Frontend
- **HTML5**: Semantic markup and accessibility features
- **CSS3**: 
  - Custom properties (CSS variables)
  - Flexbox and Grid layouts
  - Media queries for responsive design
  - Smooth animations and transitions
- **JavaScript (ES6+)**:
  - DOM manipulation
  - Event handling
  - Form validation
  - API integration

### External Services & Libraries
- **EmailJS**: For contact form and meeting request functionality
- **Font Awesome**: Icon library for UI elements
- **Google Calendar API**: For meeting scheduling integration

The portfolio includes two methods of contact:
